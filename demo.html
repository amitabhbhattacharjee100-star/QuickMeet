🚀 Quick Setup Guide

❌ Node.js Not Detected
You need to install Node.js first to run the full application.

Step 1: Install Node.js

Download and install from: https://nodejs.org/

Choose the LTS (Long Term Support) version.

Step 2: Install Dependencies

After installing Node.js, open PowerShell in this folder and run:

npm install
cd server
npm install
cd ../client
npm install
cd ..

Step 3: Create Environment File

Create a file named .env in the server folder:

PORT=5000
MONGODB_URI=mongodb://localhost:27017/quickmeet
JWT_SECRET=quickmeet-secret-key-2024
NODE_ENV=development
CLIENT_URL=http://localhost:3000

Step 4: Install MongoDB

Option A: Local MongoDB - Download

Option B: MongoDB Atlas (Cloud, FREE) - Sign Up

Step 5: Start the App

Run this command from the root folder:

npm run dev

Step 6: Open Browser

Go to: http://localhost:3000

✅ Quick Start Scripts Available:
- CHECK_SETUP.bat - Check if everything is ready
- START_APP.bat - Automatically install and start the app
