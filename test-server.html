⚠️ Setup Required
This is a test page. The full app requires Node.js to run.

To Make QuickMeet Go Live:

  1. Install Node.js
    Download from: nodejs.org
  2. Install Dependencies
    Run: npm install in root, server, and client folders
  3. Create server/.env file
    See HOW_TO_RUN.md for details
  4. Start MongoDB
    Install locally or use MongoDB Atlas (free cloud)
  5. Run the app
    Run: npm run dev from root folder
  6. Open browser
    Go to: http://localhost:3000
